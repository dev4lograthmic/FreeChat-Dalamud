# FreeChat.Protocol

C# bindings and shared protocol constants for FreeChat v1.

- `Generated/` is produced by `buf generate` from `proto/freechat/v1/*.proto`.
  Do not edit these files by hand.
- The project references the `Google.Protobuf` runtime.
- The `.csproj` is added in Phase 2 together with the server core.

Regenerate:

```bash
buf generate
```
